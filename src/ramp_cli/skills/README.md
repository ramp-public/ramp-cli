# Ramp CLI skills

Bundled agent skill instructions for AI agents. Each subdirectory with a
`SKILL.md` is a skill. Install into your agent project with:

```bash
ramp skills list
ramp skills install spend-analysis
```

## Available skills

| Skill | Summary |
| ----- | ------- |
| `agentic-purchase` | Make purchases using Ramp agent cards via browser checkout |
| `apply-to-ramp` | Start or complete a Ramp financing application |
| `approval-dashboard` | Review and approve pending transactions, bills, reimbursements, and requests |
| `book-flight` | Book flights through the CLI with search, compare, and ticket on approval |
| `browser-automation` | Automate Chrome for navigate, forms, snapshots, and content extraction |
| `card-management` | Inspect card/fund status, activate or lock/unlock cards |
| `get-started` | Agent onboarding playbook for Ramp CLI workflows |
| `incorporate-with-ramp` | File a US LLC through Ramp to resolve incorporation blockers |
| `manage-bills` | Search, inspect, and manage vendor bills and invoices |
| `manage-procurement` | Review procurement requests and purchase orders |
| `payment-lookup` | Look up vendor bill payments and verify payment status |
| `receipt-compliance` | Find transactions missing receipts and upload them |
| `spend-analysis` | Analyze spend by vendor, category, or team over a date range |
| `submit-procurement-request` | Submit and track procurement requests through Ramp |
| `submit-reimbursement` | Submit an out-of-pocket reimbursement from a receipt |
| `transaction-cleanup` | Complete missing memos, categories, funds, and attendees |
| `vendor-document-upload` | Upload W-9, contracts, COIs, and vendor onboarding documents |

Skills are also listed by `ramp skills list` and documented in the
[Cursor plugin](https://github.com/ramp-public/cursor-plugin).
